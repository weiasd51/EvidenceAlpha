# 面试追问清单

## 一分钟项目介绍

EvidenceAlpha 是一个面向 A 股事件研究的证据驱动多智能体系统。它解决传统金融 Agent 结论不可追溯、历史回放可能泄漏未来数据、效果缺少量化验证的问题。系统冻结研究时点，组织 Research、Bull、Bear、Critic 和 Judge 基于同一证据集分析，并把结构化预测写入账本，在到期后计算方向准确率、Brier Score 和超额收益，形成可复现的评测闭环。

## 高频问题

### 为什么需要多 Agent？

多 Agent 不是目标，而是实验变量。系统保留 Single、Debate 和 Debate+Memory 三种模式，用相同证据和样本做消融实验。如果 Debate 没有带来校准或准确率改善，就不应为复杂度买单。

### 如何防止未来函数？

分析请求包含 `as_of`。Provider 只返回 `published_at <= as_of` 的证据；Prediction 创建后只追加结算结果，不修改原始判断。测试中包含历史时点断言。

### 为什么用 Brier Score？

准确率只判断方向是否正确，无法惩罚过度自信。Brier Score 衡量概率预测与真实结果的平方误差，高置信度错误会受到更大惩罚。

### 为什么不用 LLM 计算收益？

收益率、基准和指标属于确定性计算，必须由程序完成。LLM 只负责证据归纳、反向质疑和错误解释，避免数值幻觉。

### 当前版本有什么不足？

当前公开版本默认使用可复现演示数据，真实行情和公告 Provider、交易日历、异步任务、向量记忆和大规模历史实验仍是后续工作。README 不宣称尚未实测的收益或准确率。
